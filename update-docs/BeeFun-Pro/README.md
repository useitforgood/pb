# BeeFun Pro

Native iOS GitHub client built with Swift 5. Browse trending repositories, manage starred repos, track notifications and events, and read issues and user profiles — all from a clean native UI.

- App Store (iOS): https://apps.apple.com/cn/app/beefun-pro/id1393808664
- Source: https://github.com/wenghengcong/BeeFun-Pro

## Features

- Trending repository discovery (daily / weekly / monthly)
- Search repositories and developers
- Starred repository management with custom tags
- Notification and event feeds
- Issues browser
- User and repository detail pages
- GitHub OAuth2 login
